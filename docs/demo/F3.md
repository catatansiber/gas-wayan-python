# Demo F3 - Importer Raw dan Staging

Belum ada UI review (F4). Demo memakai dua management command:
`import_workbook` (baca workbook -> raw + staging) dan `import_report` (ringkasan).

Perintah di bawah membaca `../SERI TABUNG.xlsm` (read-only, checksum diverifikasi otomatis
sebelum baris pertama diproses). **Jangan mencetak nilai mentah (`Nomor Tabung`, `Nama Relasi`)
ke terminal/log** - dokumen ini sengaja tidak menyertakan perintah yang menampilkan isi
`docs/reports/f3-local/*.csv` (file itu sudah berisi data asli untuk direview manual, LOKAL
SAJA, jangan disalin ke chat/Git).

## 0. Tes otomatis dulu (bukti tanpa data asli)

```powershell
python manage.py test imports --settings=config.settings.test -v 2
```

**Expected:** `Ran 25 tests ... OK`.

## 1. Dry-run (pratinjau, tidak menulis apa pun)

```powershell
python manage.py import_workbook --dry-run
```

**Expected:** ringkasan `[DRY-RUN (tidak disimpan)]` dengan `Baris fisik dibaca: 11137`,
`Baris kosong: 540`, `RawRow baru: 11137`, `StagingRow baru: 10597`. Cek database tidak berubah:

```powershell
python manage.py shell -c "from imports.models import RawRow; print(RawRow.objects.count())"
```

**Expected:** `0` (dry-run rollback total).

## 2. Import sungguhan

```powershell
python manage.py import_workbook
```

**Expected:** `[TERSIMPAN]`, angka sama seperti dry-run (`RawRow baru: 11137`,
`Baris kosong: 540`, `StagingRow baru: 10597`).

## 3. Jalankan ulang - buktikan idempotent

```powershell
python manage.py import_workbook
```

**Expected:** `RawRow baru: 0`, `RawRow sudah ada: 11137`, `StagingRow baru: 0`,
`StagingRow sudah ada: 10597`. Tidak ada baris raw/staging ganda.

## 4. Tiga baris terakhir (10.599-10.601) - buktikan berisi data, bukan blank

```powershell
python manage.py shell -c "
from imports.models import RawRow
for n in [10599, 10600, 10601]:
    r = RawRow.objects.get(source_row_number=n)
    print(n, 'is_blank=', r.is_blank)
"
```

**Expected:** ketiganya `is_blank= False`. Baris fisik terakhir (11.138 dan sekitarnya) blank -
bisa dicek dengan mengganti nomor baris, tapi jangan mencetak isi kolomnya.

## 5. Checksum tidak berubah setelah dibaca berulang kali

```powershell
# PowerShell, dari root Gas-Wayan-Python (satu level di atas gas-wayan-python/)
```

**Expected:** `D96FC4E7366BFC9B38CBD2BEB6985CAB361BCA9E1D36CFAED5DD1FFDDFA33B81` (persis sama
sebelum dan sesudah langkah 1-4 di atas).

## 6. Laporan agregat (aman, tanpa data asli) + laporan detail (lokal saja)

```powershell
python manage.py import_report
```

**Expected:** `docs/reports/f3-import-summary.json` berisi hitungan agregat saja (buka file ini
langsung, aman dibaca/dibagikan). `docs/reports/f3-local/*.csv` berisi data asli per baris
bermasalah/kandidat duplikat/kandidat alias - buka lewat Excel/editor teks di komputer sendiri,
**jangan** ditempel ke chat, tiket, atau dokumen yang masuk Git (folder ini sudah di-gitignore).

**Expected:** error `Checksum workbook tidak cocok`, tidak ada `ImportBatch`/`RawRow` baru
ditulis (bisa diverifikasi lewat `ImportBatch.objects.count()` sebelum/sesudah tidak berubah).

## Contoh kasus tanggal campuran dan status legacy (fixture sintetis, aman dibagikan)

Tes `imports/tests.py::ImportWorkbookTests.test_mixed_date_formats` dan
`test_returned_keyword_*`/`test_sdh_balik_not_mapped_to_returned` mendemonstrasikan lewat data
sintetis (bukan data pelanggan asli):

- `08/09/2025` (native Excel date) -> `sent_at_is_native=True`.
- `9.9.25` (teks, tahun 2 digit) -> `2025-09-09`.
- `31/2/25` (mustahil) -> tidak terparse, `review_status=NEEDS_REVIEW`, tidak pernah ditebak.
- `K`/`KEMBALI`/`Sdh Kembali` -> `returned_status` sesuai keyword, `returned_date_unknown=True`.
- `SDH BALIK` -> `returned_status=SDH_BALIK`, tetap `NEEDS_REVIEW` (belum dipetakan ke RETURNED,
  MIG-B05 masih `PENDING`).
- `GANTI TABUNG` (teks bebas lain) -> `returned_status=OTHER_TEXT`, `NEEDS_REVIEW`.

Jalankan satu per satu untuk lihat detail:

```powershell
python manage.py test imports.tests.ImportWorkbookTests.test_mixed_date_formats -v 2
python manage.py test imports.tests.ParsingUnitTests -v 2
```
