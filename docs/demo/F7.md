## 5. Backup/restore (drill sungguhan - opsional, butuh Docker)

```powershell
docker exec gas-wayan-python-postgres-1 pg_dump -U gaswayan -d gaswayan_dev -F c -f /tmp/backup.dump
docker exec gas-wayan-python-postgres-1 psql -U gaswayan -d postgres -c "CREATE DATABASE gaswayan_restore_test OWNER gaswayan;"
docker exec gas-wayan-python-postgres-1 pg_restore -U gaswayan -d gaswayan_restore_test /tmp/backup.dump
docker exec gas-wayan-python-postgres-1 psql -U gaswayan -d gaswayan_restore_test -c "SELECT count(*) FROM imports_rawrow;"
```

**Expected:** jumlah baris `imports_rawrow` di database restore sama dengan `gaswayan_dev`
(11.137 pada snapshot saat ini). **Bersihkan setelah selesai:**

```powershell
docker exec gas-wayan-python-postgres-1 psql -U gaswayan -d postgres -c "DROP DATABASE gaswayan_restore_test;"
docker exec gas-wayan-python-postgres-1 rm -f /tmp/backup.dump
```

## 6. Performa (data sintetis, sudah dijalankan sesi ini - lihat hasil)

```powershell
python manage.py perf_benchmark --settings=config.settings.test --cylinders 3000 --customers 300 --cycles 20000 --samples 30
```

**Expected:** ringkasan p50/p95 per operasi tercetak, data sintetis otomatis dibersihkan di
akhir (bisa diverifikasi: `Cylinder.objects.filter(serial_number__startswith="PERF-").count()`
harus `0` setelah selesai). Hasil lengkap: `docs/reports/f7-performance.json`. **Baca catatan
interpretasi di `docs/reports/F7.md` sebelum menyimpulkan apa pun soal kapasitas produksi.**
