```powershell
python manage.py test imports --settings=config.settings.test -v 2
```

**Expected:** `Ran 37 tests ... OK`, mencakup crash/resume, re-run, duplikat bisnis, rollback

## 1. Layar review Admin (Django Admin)

```powershell
python manage.py runserver
```

Buka `http://127.0.0.1:8000/admin/imports/stagingrow/` (login sebagai user role ADMIN).

- Filter `publish_outcome = PENDING_REVIEW` dan `review_status = NEEDS_REVIEW` untuk lihat baris
  yang tertahan kebijakan PENDING (gas/tanggal/status kembali).
- Klik satu baris - lihat **"Preview mapping"** di atas form (pelanggan cocok/baru, tabung
  ada/baru, kode gas, layak publish sekarang) - dihitung saat dibuka, belum menulis apa pun.
- Pilih satu/lebih baris, aksi **"Kecualikan dari publish (wajib alasan)"** - coba submit tanpa
  isi alasan (ditolak), lalu isi alasan dan submit (tercatat sebagai `ReviewDecision`).

## 2. Publish (dry pertama - lihat hasil tanpa menulis lewat --limit-serial pada data sintetis)

Untuk demo aman tanpa membuka data pelanggan asli, gunakan `manage.py shell` dengan data
sintetis (sama seperti demo F2):

```python
from datetime import date
from identity.models import Role, User
from imports.models import ImportBatch, RawRow, StagingRow
from imports import parsing, publisher

admin = User.objects.filter(role=Role.ADMIN).first()
batch = ImportBatch.objects.create(
    workbook_filename="demo.xlsm", workbook_sha256="d" * 64, sheet_name="Database",
    parser_version=parsing.PARSER_VERSION,
)
raw = RawRow.objects.create(
    workbook_sha256=batch.workbook_sha256, sheet_name="Database", source_row_number=99999,
    is_blank=False, raw_json={}, first_seen_batch=batch,
)
staging = StagingRow.objects.create(
    raw_row=raw, parser_version=parsing.PARSER_VERSION, serial_number_raw="DEMO-F4-0001",
    serial_number_present=True, customer_name_raw="Demo Pelanggan F4",
    customer_name_normalized=parsing.normalize_customer_name("Demo Pelanggan F4"),
    sent_at=date(2025, 1, 1), sent_at_is_native=True, sent_at_parseable=True,
    returned_at=date(2025, 1, 5), returned_at_is_native=True,
    returned_status=StagingRow.ReturnStatus.DATE, gas_code_raw="O2", gas_type_code="O2",
    gas_type_known=True, review_status=StagingRow.ReviewStatus.READY, import_batch=batch,
)

result = publisher.run_publish(admin, limit_serials=["DEMO-F4-0001"])
print(result.status, result.groups_published, result.rows_published)  # COMPLETED 1 1
staging.refresh_from_db()
print(staging.publish_outcome)  # PUBLISHED
print(staging.source_link.cycle.status, staging.source_link.cycle.close_reason)  # CLOSED RETURNED
```

**Expected:** `COMPLETED 1 1`, lalu `PUBLISHED`, lalu `CLOSED RETURNED`.

## 3. Re-run - buktikan idempotent

```python
result2 = publisher.run_publish(admin, limit_serials=["DEMO-F4-0001"])
print(result2.groups_published, result2.groups_already_resolved)  # 0 1
```

## Bersihkan data demo (langkah 2-4)

```python
from imports.models import SourceLink
from operations.models import Cycle, LifecycleEvent
from catalog.models import Customer, CustomerAlias, Cylinder

SourceLink.objects.filter(staging_row__serial_number_raw__startswith="DEMO-F4-").delete()
StagingRow.objects.filter(serial_number_raw__startswith="DEMO-F4-").delete()
RawRow.objects.filter(source_row_number__in=[99997, 99998, 99999]).delete()
batch.delete()

# Urutan wajib: LifecycleEvent -> Cycle -> Cylinder (semua PROTECT, lihat operations/models.py).
demo_cylinders = Cylinder.objects.filter(serial_number__startswith="DEMO-F4-")
LifecycleEvent.objects.filter(cylinder__in=demo_cylinders).delete()
Cycle.objects.filter(cylinder__in=demo_cylinders).delete()
demo_cylinders.delete()
CustomerAlias.objects.filter(customer__display_name="Demo Pelanggan F4").delete()
Customer.objects.filter(display_name="Demo Pelanggan F4").delete()
```
