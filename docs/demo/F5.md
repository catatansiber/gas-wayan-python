# Demo F5 - Layar Operasional Web

## 0. Tes otomatis dulu

```powershell
python manage.py test operations.test_views --settings=config.settings.test -v 2
```

**Expected:** `Ran 21 tests ... OK`.

## 1. Jalankan server dan buka di browser

```powershell
python manage.py runserver
```

Buka `http://127.0.0.1:8000/login/`, masuk sebagai user role OPERATOR (buat lewat
`python manage.py createsuperuser` lalu ubah role di Admin, atau `manage.py shell` seperti demo
F2). **Coba lebar layar 360px** (DevTools browser -> device toolbar) dan desktop penuh - layout
harus tetap terbaca, tabel bisa di-scroll horizontal bila sempit, tidak ada elemen terpotong.

## 2. Alur normal: cari -> kirim -> lihat riwayat -> kembali

1. Buka **Cari tabung**. Kosongkan form dan submit - tidak ada hasil (belum ada pencarian).
2. Cari nomor tabung yang belum pernah dipakai, mis. `DEMO-F5-0001` - tampil
   **"Tabung dengan nomor tersebut tidak ditemukan."**
3. Buat data via `manage.py shell` (data sintetis):
   ```python
   from catalog.models import Customer, Cylinder
   Customer.objects.create(display_name="Demo Pelanggan F5")
   Cylinder.objects.create(serial_number="DEMO-F5-0001")
   ```
4. Cari lagi `DEMO-F5-0001` - sekarang muncul, status `AVAILABLE`.
5. Buka **Kirim**, isi nomor tabung, pilih pelanggan, jenis gas, tanggal kirim - submit.
6. Halaman **preview** muncul - periksa ringkasan, klik **Konfirmasi** SATU KALI.
7. Diarahkan ke halaman detail tabung - status `OUT`, siklus aktif menampilkan pelanggan.
8. Buka **Log penggunaan** - event `DISPATCHED` muncul dengan waktu dalam WITA (Asia/Makassar).
9. Buka **Kembali**, isi nomor tabung + tanggal kembali - preview - konfirmasi.
10. Status tabung kembali `AVAILABLE`, riwayat siklus menampilkan baris RETURNED.

## 3. Coba input salah

- Di form Kirim, isi tanggal kirim **di masa depan** - submit ditolak dengan pesan
  **"Tanggal tidak boleh di masa depan."**, tidak ada preview yang muncul.
- Kosongkan nomor tabung - pesan **"Wajib diisi."** di bawah field.
- Di form Tukar (Admin), isi tabung lama = tabung pengganti - pesan
  **"Tabung lama dan tabung pengganti tidak boleh sama."**
- Coba kirim tabung yang statusnya masih `OUT` - preview lolos, tapi setelah **Konfirmasi**
  muncul pesan error domain F2 (mis. "tidak dapat dikirim") - tidak ada siklus baru terbentuk.

## 4. Idempotency double-click

Di halaman preview kirim/kembali, klik tombol **Konfirmasi dua kali dengan cepat** (atau buka
DevTools Network dan kirim ulang request POST yang sama persis). **Expected:** hanya SATU
`Cycle`/`LifecycleEvent` tercipta - cek lewat Django Admin (`/admin/operations/cycle/`) atau:

```python
from operations.models import Cycle
Cycle.objects.filter(cylinder__serial_number="DEMO-F5-0001").count()  # tetap 1
```

## 5. Role terlarang

- Masuk sebagai VIEWER - buka `/operasi/kirim/` langsung dari URL bar - **403 Akses ditolak**
  (halaman `templates/403.html`), bukan hanya tombol yang hilang di UI.
- Masuk sebagai OPERATOR - buka `/operasi/admin/tukar/` - **403 Akses ditolak** (fungsi Admin
  tetap ditolak server meski URL diketik langsung).

## 6. Hasil pencarian kosong

- Cari nama pelanggan yang tidak ada sama sekali - **"Tidak ada hasil untuk pencarian ini."**
- Perhatikan: setiap pencarian me-render ulang halaman dari server (bukan AJAX/JS), jadi hasil
  yang tampil SELALU sesuai query saat ini - tidak ada hasil pencarian lama yang tertinggal.

## 7. Timezone

Setelah langkah 2, buka detail tabung dan lihat kolom **"Waktu (Asia/Makassar)"** di log
kejadian - bandingkan dengan `LifecycleEvent.created_at` mentah (UTC) di Django Admin
(`/admin/operations/lifecycleevent/`) - selisihnya harus tepat +8 jam (WITA).

## Bersihkan data demo

```python
from catalog.models import Customer, Cylinder
from operations.models import Cycle, LifecycleEvent
cyl = Cylinder.objects.filter(serial_number="DEMO-F5-0001").first()
if cyl:
    LifecycleEvent.objects.filter(cylinder=cyl).delete()
    Cycle.objects.filter(cylinder=cyl).delete()
    cyl.delete()
Customer.objects.filter(display_name="Demo Pelanggan F5").delete()
```
